# Kitten TTS 2 Mini

앱을 시작한 후 로그에 `Wyoming listening`이 표시되면 **설정 → 기기 및 서비스**에서 검색된 Wyoming 통합을 설정합니다. **설정 → 음성 어시스턴트**에서 텍스트 음성 변환 엔진으로 Kitten TTS 2 Mini를 선택합니다.

첫 시작에는 모델 다운로드를 위한 인터넷 연결이 필요합니다. 모델 캐시는 앱 데이터에 저장됩니다.

## 설정

| 옵션 | 기본값 | 설명 |
| --- | --- | --- |
| `language` | `ko` | 기본 음성의 언어입니다. `ko`와 `en`을 지원합니다. |
| `voice` | 비어 있음 | 언어의 첫 음성을 사용합니다. 한국어 음성은 `Seoyeon`, `Minjun`, `Jihoon`입니다. |
| `speed` | `1.0` | 음성 속도이며 `0.5`에서 `2.0`까지 설정할 수 있습니다. |
| `debug_logging` | `false` | 디버그 로그 출력 여부입니다. |

설정을 변경하면 앱을 다시 시작합니다.
